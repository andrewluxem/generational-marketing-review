# Security

This skill does not require network access, credentials, or command execution.

Report security or privacy issues through GitHub's private vulnerability reporting feature when it is enabled for this repository. If private reporting is unavailable, do not disclose vulnerability details in a public issue. Open a minimal public issue stating only that you need a private security-reporting channel, and wait for a maintainer to arrange one before sharing technical details. Never include credentials, private campaign data, personal information, exploit steps, affected versions, or other sensitive details in a public issue.
